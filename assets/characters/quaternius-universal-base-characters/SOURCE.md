# Quaternius Universal Base Characters

This directory contains the extracted files used by the local Blender character generator.

- Creator: Quaternius
- Pack: Universal Base Characters, Standard edition
- Source: https://quaternius.com/packs/universalbasecharacters.html
- Download page: https://quaternius.itch.io/universal-base-characters
- License stated by the creator for this pack: CC0
- Retrieved: 2026-11-08
- Downloaded archive SHA-256: `fdbf1804c90dfc1ea03e992bff7da2dfd1a79318e13270a660180f9308455f40`

The project uses the male and female glTF bodies, their textures, and selected rigged hairstyles. The runtime generator adds project-original fitted clothing, role accessories, appearance variation, facial controls, and animation. Two texture aliases ending in `_png.png` are local copies added to match paths embedded in the source glTF files.
